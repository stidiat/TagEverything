# TagEverything 文件管理应用

## 简介
TagEverything 是一个基于 Windows 桌面（WPF + .NET 9）开发的文件管理与打标签工具。它允许用户集中管理各种文件，并支持针对视频格式（.mp4, .mkv 等）自动提取时长、分辨率、码率等元数据。非视频文件支持哈希与基本属性提取。通过多维度标签与搜索功能，您可以轻松找回您的资产。

## 特性
- 首次运行选择库文件夹，所有的文件、缩略图及数据库均在此目录内进行统一管理。
- 采用 Entity Framework Core + SQLite 本地存储数据与标签关系。
- 视频文件支持 FFmpeg 解析（自动下载依赖或使用内置组件）。
- 多文件拖拽导入与智能文件重复检测机制。
- 现代化 WPF 界面（MaterialDesignThemes），支持卡片视图与列表视图无缝切换。
- **强大的标签管理系统**：
  - 支持单文件和**多文件批量编辑**标签。
  - 智能的搜索框下拉提示，一键连续筛选。
  - 支持自然语义的标签提取（基于空格或逗号分隔）。
- 文件监控合并同步文件/目录重命名和内容修改。找不到原文件时保留记录和标签，并标为缺失；可右键选择库内同内容文件重新关联。外部新增文件需点击“待入库”逐个确认原地纳管。
- 文件列表每页 100 条；卡片虚拟化、可见缩略图按需加载与容量受限缓存。
- 导入队列支持进度、取消和失败重试；导入/删除操作日志支持崩溃恢复。
- 视频使用三帧 dHash 相似比较，支持阈值设置及误报反馈。
- 卡片分别显示大小和文件类型，列表拆成独立两列；文件类型无前导点且使用大写（如 TXT、MP4）；导入和主页面优先显示生成的预览，缺失或损坏时使用 Windows 系统缩略图或文件类型图标。系统回退仅用于显示，不写入数据库或参与相似检测。
- **极简绿色的打包策略**：主程序仅 ~20MB，依赖项独立放置于 `bin` 目录。

## 使用说明

### 安装与运行
1. 下载 `TagEverything_Setup.exe` 安装包并运行。
2. 安装后首次启动，应用将提示您选择一个“库文件夹”（Library Folder）。
3. 随后，应用会在该目录的 `TagEverythingData/library.db` 初始化数据库。用户设置保存在 `%LocalAppData%/TagEverything/settings.json`，不会写入安装目录。

### 导入文件
- **点击导入**：在主界面顶部点击“导入文件”按钮，在文件对话框中选择。
- **拖拽导入**：直接从资源管理器拖拽文件到主窗口区域。
- **详情弹窗**：导入时会弹出文件详情。在其中可输入标签（使用空格或逗号分隔），点击“确认导入”后将复制文件到库中。

### 管理与编辑
- **鼠标拖拽多选**：无论在卡片视图还是列表视图中，在空白处按下鼠标左键并拖拽，即可出现蓝色选框，快速框选多个文件。
- **批量编辑标签**：选中多个文件后右键点击，选择“编辑标签”。在弹窗中可以为所有选中的文件统一添加新标签，或者一键移除它们共有的标签。
- **单文件编辑**：右键单个文件选择“编辑标签”，点击现有标签可以为其划上删除线，点击“保存”即可应用更改。

### 搜索与过滤
- **智能下拉提示**：点击右上角搜索框，会自动弹出当前库中所有可用标签的下拉列表，点击即可快速添加为过滤条件，支持连续点击多选。
- **标签快捷输入**：在搜索框中手动输入 `#标签名` 并按下**空格**或**逗号**，程序会自动将其提取为彩色的过滤胶囊。
- **组合搜索**：支持将多个标签胶囊与文件名组合。例如：搜索框中有 `[holiday]` 胶囊，同时输入了文本 `vacation`，则表示查找包含 holiday 标签且文件名包含 vacation 的文件。
- **字面搜索**：`%`、`_` 等符号按实际字符匹配。顶部支持刷新列表和一键清空筛选；加载时显示进度条，翻页按钮在边界自动禁用。

### 快捷键与操作
- `Enter`：在标签输入框内按下可快速应用当前输入的标签。
- `双击左键`：在卡片列表区双击文件可直接调用系统默认应用打开源文件。
- `.library 文件关联`：双击 `.library` 文件可切换到对应库。空文件表示其所在目录；文件内容也可以是库目录路径或包含 `LibraryPath` 的 JSON。

## 测试报告
- **测试框架**: xUnit
- **覆盖范围**: 
  - `HashService`（计算 SHA-256）
  - `MetadataExtractionService`（识别视频与扩展名）
  - `FileSearchService`（真实 SQLite 内存库，验证符号、大小写、组合条件和取消）
  - 重复检测（相同大小不误判、SHA-256 精确匹配）
  - 安全文件暂存、唯一文件名与路径越界防护
  - SQLite 感知哈希完整范围及标签大小写唯一性

使用变化与本地验证步骤见 [发布说明](docs/RELEASE_NOTES.md)。
